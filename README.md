# Save State Studio — Social Media Kit

Standalone reference page for the Save State Studio LinkedIn/Instagram
launch. This is the studio behind [Apex Lifter](https://apexlifter.ch),
not the product itself: a one-person studio run in the evenings and
weekends alongside a full-time job, focused on honest software at a
fair price — no ads, no growth-hacking, no marketing fluff.

Open `index.html` directly in a browser, or serve the folder with any
static file server.

## Contents

- `index.html` — the kit itself: account setup steps, profile texts,
  content strategy, a four-week content calendar, five ready post
  drafts (4 Instagram + 1 LinkedIn), and all image assets
- `images/` — profile picture, LinkedIn banner, and 4 Instagram post
  images, all built around the pixel-art floppy disk icon and gold
  accent (deliberately without the Apex Lifter product's violet, for a
  calmer "studio, not product" look)
